# 🚀 Featured Projects

## 👕 Garment Design System

**Full-stack Garment Manufacturing Service Platform**

A full-stack web application for managing garment-related services, users, orders, files, reviews, and customer workflows.

The project consists of multiple repositories representing different stages and parts of the system.

### ✨ Main Features

* 👤 User registration & authentication
* 🔐 Spring Security session-based authentication
* 🍪 HTTP Session / JSESSIONID
* 🛡️ Role-based authorization
* 🔑 BCrypt password encryption
* 🛡️ CSRF protection
* 🌐 Google authentication
* 📱 Phone / OTP authentication flow
* 🔄 Forgot & reset password flow
* 👤 User profile management
* 📍 Address management
* 👕 Garment service management
* 📦 Service order management
* 📁 Order file management
* ⭐ Service reviews
* 📧 Contact email system
* 📰 Newsletter subscription
* 📊 Dashboard & statistics
* 📤 User data export
* 🎨 Responsive and reusable UI components

### 🛠️ Tech Stack

**Frontend**

`React` • `Tailwind CSS` • `Vite` • `React Router` • `Axios`

**Backend**

`Java` • `Spring Boot` • `Spring Security` • `Spring Data JPA`

**Database**

`Microsoft SQL Server`

**Security**

`HTTP Session` • `JSESSIONID` • `CSRF` • `BCrypt` • `Role-based Authorization`
